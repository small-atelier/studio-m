Same profile as the common 40mm Spearhead objective coins, so it sits flush with the surrounding tiles:

- 40mm diameter, 2mm thick.
- 1mm base, with a raised rim 2mm wide and 1mm high.
- Mythos icon raised 1mm in the field, level with the rim, 26.4 × 20.0mm.

A set of six goes with the [AoS Objective Markers]({{< ref "/printables/aos-objective-markers" >}}).

## Printing

Single material, made for resin. Print the same STL six times.
