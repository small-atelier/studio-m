A Prospero-themed terrain board for the [Thousand Sons]({{< ref "/armies/thousand-sons" >}}): their ruined homeworld, built as a set of modular, gameplay-first terrain pieces.

Iconic Prospero themes — crystal spires, stepped pyramids, arcane obelisks, marble ruins, floating psychic islands — built as a collection of playable pieces rather than one static diorama, so each piece can be repositioned between missions.

**Design brief:** desert/ash-wastes theme, gameplay before looks, no standing on terrain, ~25–33% LOS-blocking coverage split evenly across both halves, modular pieces, board size 44"×60" (matches Strike Force / Incursion). Building is the fun part — painted finish is secondary.

- [Prospero Pyramid](pyramid) — centerpiece, stepped ritual temple
- [Arcane Obelisks](obelisks) — objective markers
- [Crystal Energy Fields](crystals) — scatter terrain
- [Floating Crystal Forest](forest) — floating island pylons
- [Temple Ruins](ruins) — filler terrain, cover
- [Columns](columns) — standing & broken columns for the ruins
- [Brazier](brazier) — flame finial attachment piece
- [Rune Panels](runes) — engraved cladding panels
