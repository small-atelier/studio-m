## Terrain — Prospero Board

Iconic Prospero themes — crystal spires, stepped pyramids, arcane obelisks, marble ruins, floating psychic islands — built as a collection of playable pieces rather than one static diorama, so each piece can be repositioned between missions.

**Design brief:** desert/ash-wastes theme, gameplay before looks, no standing on terrain, ~25–33% LOS-blocking coverage split evenly across both halves, modular pieces, board size 44"×60" (matches Strike Force / Incursion). Building is the fun part — painted finish is secondary.
