## Terrain

| Category | Examples                              |
|----------|---------------------------------------|
| Exposed  | craters, razorwire, debris            |
| Light    | barricades, low walls, statuary       |
| Dense    | buildings, ruins, containers, woods   |

Terrain sits in **terrain areas**: the base, mat or outline the features stand within.

For building:

- **Ground floor:** the first 3" of a dense feature counts as a solid wall, whatever the window and door cut-outs.
- **Low sections:** vehicles only pass through dense sections 2" tall or less.
- **Upper floors:** need flat, stable surfaces with room for a whole base.

## Objectives

- **Terrain objectives:** by default each objective is a terrain area, so the terrain piece is the objective and no marker is needed.
- **Marker objectives:** an objective outside any terrain area is a flat 40mm marker with 3" range. Printable: [AoS objective markers]({{< ref "/printables/aos-objective-markers" >}}).
