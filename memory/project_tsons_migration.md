**Card stand, resolved 2026-08-12** — moved from `content/projects/card-stand/` to `content/posts/card-stand/` (a leaf bundle now, for the `gallery/*` carousel) — it's a one-off gift piece with a technique story, not a miniature project or owned inventory, so it fit the same slot as `blender-bases.md` rather than `projects/` or `inventory/`. Backstory: a new local store, Mythos (mythos.nu), opening nearby — made them a counter card stand and used it to practice two techniques: stamping a logo in from a raster photo (v3's per-pixel heightfield, replaced in v4/v5 by marching-squares vector contours → flat sharp-edged plateau — crisper and easier to hand-paint), and a genuinely zero-support resin print (v5 reoriented the backplate flat-on-back so every relief feature projects the same direction). Page has the full v1→v5 iteration table (unlike drawers, iterations were wanted here) plus the two data-pipeline scripts (`preprocess_logo.py`, `extract_logo_contours_v5.py`) inlined via `{{< include-code >}}`. **Update 2026-08-12:** added a Downloads section after all (`backplate.stl`, `card-holder.stl`, `text-plate.stl`) — user's call, framed as "the owner might want to reprint/tweak it themselves," not as a general-purpose reusable design.

**Real-world print feedback, 2026-08-12:** printed and reported back — flat-on-back zero-support print worked but needed sanding after support removal, and the wordmark (real vector text unioned onto the backplate) broke on O and S during handling, too thin at that stroke width/size. Built `blender/card-stand/text_plate_v1.py` as the fix: a standalone 2mm plate, letters raised 1.8mm + embedded 1.2mm into the plate (real union with volume behind it, not a thin graze), bolded via Blender curve `offset` rather than just scaling the font up (offset thickens every stroke edge including O's ring/S's curve; plain size increase would've made the same thin-relative-to-size problem bigger, not fixed it). **Actually ran this in Blender** (not just written blind — `/Applications/Blender.app` is present on this machine) and found the offset has a hard ceiling: past ~0.13mm it self-intersects O/S's tight curves and the union silently collapses most of the letterforms (mesh volume ~3000mm³ → ~200mm³, non-manifold fraction jumps to 12%) — verified visually via cropped before/after renders, not just the volume number. Locked in 0.12mm as the safe bold value. Output at `blender/card-stand/output_text_plate_v1/` (`text_plate.stl` + render). User's plan: file the broken text off the existing physical backplate, glue this part on by eye rather than reprinting the backplate — so the plate's design doesn't need to match the backplate's coordinate system, just its own footprint. Documented as a "Lessons from printing" section added to the published post (`content/posts/card-stand/index.md`), with the render as a figure (`content/posts/card-stand/text-plate.png`). Not yet printed/glued at time of writing — the post describes the plan, not a confirmed final result.
